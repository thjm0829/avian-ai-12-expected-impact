# 12. 기대효과

> **작성 상태:** 세부 내용 작성 완료  
> **작성 기준일:** 2026년 8월 27일  
> **핵심 전제:** 본 시스템은 고병원성 조류인플루엔자를 확진하거나 법정 방역조치를 자동 결정하는 장비가 아니라, 농장 내부 반복검사와 자동재검을 통해 **공식검사가 필요한 시점을 더 빨리 포착하고 방역자원을 위험농가에 우선 배분하도록 지원하는 조기경보·예찰보조 시스템**이다.

## 핵심 결론

본 사업의 기대효과는 다음 인과경로로 검증한다.

> **반복검사와 디지털 기록 → 이상신호 자동선별 → 자동재검과 관리자 확인 → 공식검사 연결시간 단축 → 초동대응 우선순위 향상 → 농장 간 추가 전파와 관련 공공비용 감소 가능성**

마지막 단계인 추가 전파·살처분·재정지출 감소는 실증 전의 가설이다. 따라서 본 장은 검증되지 않은 절감률이나 피해예방액을 확정성과로 제시하지 않고, **직접 산출물(Output)·운영성과(Outcome)·장기 공공영향(Impact)**을 구분한다.

### 최종 제출본의 최우선 KPI 3개

| KPI | 핵심 정의 | 검증시점 |
|---|---|---|
| 경보 선행시간 | 시스템 경보가 임상인지·예정검사·공식 확인보다 얼마나 앞섰는지 사건별 비교 | 전문기관·농장실증 |
| 유효 반복검사 운영성 | 장치 가동률, 유효검사율, 자동재검 완료율을 함께 평가 | Mock·정상농장 운영 |
| 공공 방역연결 효과 | 경보 후 관리자 확인, 공식검사 요청·접수와 초동조치 개시까지의 시간 | 공공실증 |

나머지 KPI는 위 3개를 해석하거나 경제효과를 사후 계산하기 위한 보조지표로 둔다.

| 효과수준 | 본 사업에서 확인할 내용 | 평가 가능 시점 |
|---|---|---|
| 직접 산출물 | 검사 완료, 유효검사, 자동재검, 경보·조치이력 생성 | 시제품·농장 운영검증 |
| 운영성과 | 관리자 개입시간, 경보 확인시간, 공식검사 연결시간, 우선순위 활용 | 소수농장 실증·유료실증 |
| 공공영향 | 추가 발생농가, 예방적 살처분 대상, 재정·사회적 비용 변화 | 충북 지역사업·다지역 비교 |
| 사업확산 | 후속구매, 반복계약, 참여농가·지자체 확대 | 유료실증 이후 |

## 기대효과의 근거수준

| 구분 | 현재 표현 | 확정 시점 |
|---|---|---|
| 직접 산출물 | 장치가 생성해야 할 검사·QC·재검·경보 기록 | 시제품 시험 |
| 운영효과 | 업무시간·경보확인·공식검사 연결의 개선가설 | 농장·전문기관 실증 |
| 재정효과 | 9장 비용과 공식 보상·처리단가를 이용한 조건부 산식 | 지역사업 사후평가 |
| 방역효과 | 추가 전파와 예방적 살처분 감소 가능성 | 비교설계와 공식결과 확보 후 |
| 지역효과 | 충북형 운영모델·공급망·인력의 기대효과 | 유료실증·재계약 이후 |

공모전에서는 효과가 발생하는 인과경로와 측정방법을 제시한다. 공모전 이후 실제 기준값과 비교군을 확보하기 전에는 탐지시간 단축, 살처분 감소율, 예산절감액과 고용효과를 확정성과로 제시하지 않는다. 9장의 가격·원가가 견적으로 갱신되면 본 장의 비용편익 시나리오도 함께 갱신한다.

## 12.1 농가 효과

### 1. 이상신호 인지와 후속조치 시점 단축

현재 농가 신고와 임상예찰은 중요한 초동수단이지만, 폐사 증가·산란율 저하·사료섭취 감소와 같은 변화가 뚜렷해진 뒤 인지될 수 있다. 본 시스템은 분변 통합시료를 반복 검사하고 동일 농장의 기준선과 T/C 신호 변화를 기록하여, 단일 검사나 육안관찰만으로 판단하기 어려운 변화에 대해 재검 필요성을 제시한다.

농가에 기대되는 직접효과는 다음과 같다.

- 정해진 운영계획에 따른 반복검사 이력 확보
- 육안 판독을 보조하는 고정 카메라 기반 결과기록
- Invalid·Uncertain·변화추세 발생 시 자동재검
- NORMAL·WATCH·CAUTION·ALERT 단계별 행동지침 제공
- 관리자 확인이 필요한 농장·시점을 명확하게 표시
- 경보부터 재채취·현장확인·공식검사 요청까지의 이력 보존

이는 감염 여부를 자체 확정하는 효과가 아니라, **농가가 방역기관에 연락하고 추가 확인을 시작해야 할 시점을 놓치지 않도록 돕는 효과**다.

### 2. 검사·기록 업무의 표준화

자동채취·전처리·분주·판독이 계획대로 구현되면 농가 관리자가 직접 수행해야 하는 반복작업을 줄일 수 있다. 다만 완전 무인화를 전제로 하지 않으며, 소모품 교체·오류복구·경보 확인과 방역기관 연락에는 관리자가 참여한다.

| 기대효과 | 측정방법 |
|---|---|
| 수기 검사·기록 감소 | 검사 1회당 관리자 개입시간 비교 |
| 판독 기록의 일관성 | 이미지·정성결과·T/C·QC 기록 완전성 |
| 재검 누락 감소 | 재검조건 발생 건 대비 자동재검 완료율 |
| 오류대응 표준화 | 장애유형별 복구시간과 SOP 이행률 |
| 소모품 관리 개선 | 실제 사용량, 교체주기, 폐기·재고 기록 |
| 방역기관 전달정보 개선 | 시료·키트 Lot·이미지·경보·조치이력 완전성 |

### 3. 농장 경영연속성 보호 가능성

고병원성 AI가 공식 확진된 발생농장의 가금은 법정 방역조치 대상이므로, 본 시스템이 확진농장의 살처분을 자동으로 막는다고 주장하지 않는다. 농가 경영 측면의 장기 기대효과는 경보와 초동대응이 빨라졌을 때 **인접농가로의 추가 전파, 예방적 살처분, 이동제한 장기화와 생산중단의 범위를 줄일 가능성**에 있다.

평가대상은 다음과 같다.

- 경보 전후 출입차량·사람·물품 통제 개시시간
- 인접농가 현장확인과 공식검사 개시시간
- 참여지역 내 추가 발생농가 수
- 예방적 살처분 대상 마릿수와 농가 수
- 이동제한 기간과 재입식 지연기간
- 산란·출하·계열화 공급계획의 중단기간

이 효과는 시스템 설치농가의 전후비교만으로 확정하지 않는다. 동일 시즌의 비참여 농가, 유사 위험지역 또는 과거 자료를 비교대상으로 설정하고, 방역정책·철새유입·바이러스 유형·농장 차단방역 수준 등 외부요인을 함께 기록한다.

### 4. 농가 효과 KPI

| 구분 | KPI | 정의 |
|---|---|---|
| 운영 | 자동검사 완료율 | 예정검사 중 관리자 개입 없이 완료된 비율 |
| 운영 | 관리자 개입시간 | 검사·소모품 교체·오류복구에 투입한 시간 |
| 검사 | 유효검사율 | 전체 검사 중 판독 가능한 유효검사의 비율 |
| 재검 | 자동재검 수행률 | 재검조건 발생 건 중 실제 재검이 완료된 비율 |
| 대응 | 경보 확인시간 | 경보 생성부터 농장 관리자 확인까지 걸린 시간 |
| 대응 | 공식검사 요청시간 | 경보 생성부터 방역기관·전문기관 요청까지 걸린 시간 |
| 데이터 | 검사이력 완전성 | 시료·키트·이미지·위험도·조치이력이 연결된 비율 |
| 수용성 | 사용자 만족도 | 사용편의·업무부담·경보 이해도에 대한 평가 |
| 경영 | 생산중단기간 | 이동제한·살처분 영향으로 생산이 중단된 기간 |

## 12.2 정부·지자체 재정 효과

### 1. 공공 방역자원의 우선순위화

지자체와 공공 방역기관의 직접효과는 모든 농장을 동일하게 고빈도로 검사하는 것이 아니라, Risk-based Adaptive Testing 원칙 아래 위험도가 상승한 농장에 현장점검·재채취·공식검사 자원을 우선 투입할 수 있다는 점이다.

기대되는 운영효과는 다음과 같다.

- 농장별 반복검사와 경보현황의 통합관제
- WATCH·CAUTION·ALERT 농장 확인 우선순위 생성
- 현장출동 전 시료·키트·이미지·변화추세 확인
- 공식검사 결과와 장치경보의 사후비교
- 농장·기간·키트 Lot별 Invalid·오경보 분석
- 공공 담당자의 조치이력과 판단근거 보존
- 실증지역 방역보고서 작성에 필요한 데이터 자동집계

공공기관의 법정 권한은 유지한다. 시스템 위험등급만으로 이동제한·살처분·확진을 결정하지 않으며, 공식검사와 가축방역관의 판단을 지원하는 우선순위 정보로 사용한다.

### 2. 재정효과와 사회적 편익의 구분

정부·지자체 재정효과와 사회 전체의 경제적 편익은 구분해 산정한다.

> **순재정효과 = 회피된 살처분보상금 + 회피된 사체처리비 + 회피된 방역·행정비 − 시스템 총 계약예산 − 추가 확인검사비**

> **사회적 순편익 = 순재정효과 + 회피된 생산중단·재입식 지연·공급망 충격·환경부담**

살처분보상금은 정부 재정지출이지만 농가에는 이전소득이므로, 사회적 비용편익 분석에서는 생산손실과 중복 계산하지 않도록 항목별 범위를 명확히 한다. 또한 보상금, 사체처리비, 생계·소득안정비와 방역행정비가 서로 포함되는지 확인한 뒤 합산한다.

### 3. 시스템 총비용 기준

공공 경제성의 비용항목은 [9. 수익모델](https://github.com/thjm0829/avian-ai-09-revenue-model)의 총 계약예산을 사용한다. 검사빈도는 정부 공식기준으로 단정하지 않고, 농가당 연 60회·100회·150회 시나리오로 민감도를 비교한다.

| 농가당 연간 검사횟수 | 10개 농가 총검사 | 첫해 총 계약예산 | 2년 차 이후 연간 계약예산 |
|---:|---:|---:|---:|
| 60회 | 600회 | 115,000,000원 | 45,000,000원 |
| **100회** | **1,000회** | **125,000,000원** | **55,000,000원** |
| 150회 | 1,500회 | 137,500,000원 | 67,500,000원 |

농가당 연 100회를 5년간 동일하게 적용한 비교용 총 계약예산은 345,000,000원이다. 이는 최종 운영주기가 아니라 가격구조와 손익 민감도를 확인하기 위한 기준 시나리오다.

### 4. 살처분 관련 비용회피의 조건부 산정

국회예산정책처가 농림축산식품부 자료를 정리한 결과, 2016/17·2017/18·2020/21년 주요 발생기에는 총 552건이 발생하고 74,549천 마리가 살처분됐으며 관련 살처분보상금 지급액은 총 453,650백만원이었다. 이는 국가 단위 과거자료이므로 개별 농가의 평균 보상금이나 본 사업의 확정 편익으로 사용하지 않는다.

2026년 농림축산식품부 예산 산식의 평균 가축평가액 6,000원과 닭 사체처리 사업비 단가 2,150원을 이용하면 실증 이후 정책평가에 사용할 수 있는 단순 환산범위는 다음과 같다.

| 실증으로 확인된 회피 살처분 수 | 보상금·사체처리 직접비용 회피 잠재액 |
|---:|---:|
| 1만 마리 | 약 69,500,000~81,500,000원 |
| 10만 마리 | 약 695,000,000~815,000,000원 |
| 100만 마리 | 약 6,950,000,000~8,150,000,000원 |

위 표는 평균 평가액의 80~100%와 사체처리비를 적용한 **사후 정책평가용 환산값**이다. 실제 보상액은 축종·일령·시세·산란능력·오염물건·방역수칙 위반에 따른 감액 등에 따라 달라진다. 생계·소득안정비, 검사비, 이동제한 손실과 축산물 수급비용은 포함하지 않았으며, 회피 마릿수가 실증으로 확인되기 전에는 절감성과로 제시하지 않는다.

### 5. 정부·지자체 효과 KPI

| 평가영역 | KPI | 산정 원칙 |
|---|---|---|
| 검사효율 | 공식검사 우선순위 적중도 | 우선검사 농장 중 공식 양성·고위험 확인 비율 |
| 대응속도 | 경보→현장확인 시간 | 시스템·기관 시간기록 비교 |
| 대응속도 | 경보→공식검사 요청 시간 | 경보와 요청접수 타임스탬프 비교 |
| 행정효율 | 관제담당자 사용률 | 로그인·확인·조치기록 사용현황 |
| 행정효율 | 보고서 작성시간 | 기존 방식과 시스템 적용 후 비교 |
| 현장효율 | 불필요 현장출동 변화 | 경보근거와 실제 출동·검사결과 비교 |
| 재정 | 유효검사 1회당 총비용 | 장치·플랫폼·유지관리·소모품을 포함 |
| 재정 | 순재정효과 | 회피비용에서 시스템·추가검사 비용 차감 |
| 지속성 | 후속 운영계약 | 실증 이후 재계약·예산반영 여부 |

## 12.3 방역 효과

### 1. 조기경보의 방역 인과경로

세계동물보건기구(WOAH)는 고병원성 AI를 적시에 탐지하기 위한 지속적 감시와 고위험 집단에 대한 정기적·빈번한 임상·혈청·바이러스 검사를 조기경보 체계의 구성요소로 제시한다. 또한 과학적 근거가 있을 때 생산형태·야생조류 접촉·거래경로·생물보안 수준 등을 반영한 위험기반 감시설계를 허용한다.

본 사업은 이 원칙을 농장 내부의 반복 신속검사와 공공관제에 적용한다.

~~~text
설정된 Sampling Point의 분변 통합시료 반복채취
        ↓
AIV 신속항원 반복검사
        ↓
고정 카메라 자동판독과 이미지 QC
        ↓
농장별 기준선·변화추세 분석
        ↓
Invalid·Uncertain·이상신호 자동재검
        ↓
관리자 확인과 Reason Code 검토
        ↓
방역기관 연락·전문기관 공식검사
        ↓
법정 초동대응과 사후 결과 비교
~~~

이 구조의 1차 방역효과는 확진 정확도를 대체하는 것이 아니라, **공식검사 사이의 관찰정보를 보완하고 후속 확인이 필요한 시점을 앞당기는 것**이다.

### 2. 기대되는 방역효과

| 기대효과 | 직접 산출물 | 검증해야 할 결과 |
|---|---|---|
| 관찰공백 보완 | 농장별 반복검사 시계열 | 단일검사 대비 추가정보 여부 |
| 재검 누락 방지 | 자동재검과 알림 | 재검 수행률·해소율 |
| 위험농가 선별 | Risk Level·Reason Code | 공식검사 우선순위 적중도 |
| 대응시간 단축 | 경보·확인·요청 타임스탬프 | 기존 절차 대비 시간차 |
| 데이터 추적성 | 시료·키트·이미지·조치이력 | 원자료 완전성과 감사 가능성 |
| 지역확산 대응 | 농장·차량·방문 관계정보 | 역학조사 후보목록의 활용성 |
| 추가전파 감소 가능성 | 더 빠른 현장확인·이동통제 | 참여·비참여 지역 추가발생 비교 |

### 3. 핵심 방역 KPI

| KPI | 정의 | 해석상 주의 |
|---|---|---|
| 경보 선행시간 | 시스템 경보와 공식 확인검사·예정검사 사이의 시간차 | 공식검사가 예정돼 있었는지 구분 |
| 공식검사 연결시간 | 경보 생성부터 공식검사 요청·접수까지의 시간 | 기관 근무시간과 연락절차 기록 |
| 기준검사 일치도 | 전문기관 결과와 시스템 결과의 일치정도 | 공식 Label 확보 이후 계산 |
| 위양성·위음성률 | 공식검사 대비 오류비율 | 표본수와 신뢰구간 함께 제시 |
| 자동재검 수행률 | 재검조건 발생 건 중 완료된 비율 | 재검 불가 사유 별도 기록 |
| Risk Calibration | 위험등급별 실제 공식결과 발생률 | 농장·계절·축종별 편차 확인 |
| 추가 발생농가 수 | 최초 경보 이후 연관지역 추가 발생 | 역학연관성과 외부 유입 구분 |
| 예방적 살처분 대상 규모 | 법정 조치에 포함된 농가·마릿수 | 정책변경과 방역대 범위 통제 |
| 초동조치 개시시간 | 신고·이동통제·현장출동 시작시간 | 시스템 기여와 기존 신고 기여 구분 |

### 4. 효과 귀속과 비교설계

추가 발생 감소나 살처분 범위 축소를 본 시스템 효과로 주장하려면 반사실 비교가 필요하다.

- 동일 시즌의 유사 위험 비참여 농가 또는 지역을 비교군으로 설정
- 농장유형·사육규모·과거 발생·야생조류 접근성·차단방역 수준을 매칭
- 시스템 도입 전후뿐 아니라 참여군·비참여군의 동시 변화를 비교
- 바이러스 유형, 철새유입, 특별방역조치와 살처분 정책변경을 외부요인으로 기록
- 경보가 실제 공식검사·이동통제를 앞당겼는지 사건별 타임라인 검토
- 오경보로 증가한 현장출동·추가검사 비용도 편익에서 차감
- 표본이 적을 때는 절감률 대신 사례기술과 신뢰구간을 제시

2~5개 농장 실증에서는 장치·검사·대응 프로세스의 성과를 우선 검증한다. 추가 전파와 살처분 감소 같은 장기효과는 10개 농가 지역사업과 다지역 자료가 축적된 뒤 평가한다.

## 12.4 충북 지역사회 효과

### 1. 충북 실증의 지역적 필요성

농림축산식품부 자료에 따르면 2025/26 시즌 가금농장 고병원성 AI는 전국 62건이 발생했다. 2026년 3월 9일 기준 지역별 53건 중 충북은 9건으로 집계됐으며, 음성·진천·괴산·영동·옥천·증평·충주 등 여러 시군에서 발생이 확인됐다.

이는 충북이 특정 한 농장만의 문제가 아니라 산란계·오리 농장, 농장밀집지역과 축산차량 이동을 함께 고려한 지역 단위 방역운영을 검증할 필요가 있음을 보여준다. 다만 발생건수 자체를 본 사업의 시장규모나 예방 가능한 건수로 환산하지 않는다.

### 2. 충북형 공공 방역운영 모델

충북에서 기대되는 핵심 지역효과는 장비 10대를 설치하는 것보다 다음 운영표준을 확보하는 데 있다.

- 현재 대상인 계분벨트식 산란계·종계 농장의 설치환경 조사자료(오리·깔짚식 육계는 후속 Sampling 검증자료로 분리)
- 농장별 시료채취·전처리·분주·판독 표준절차
- 충북 지자체·농장·전문기관 간 경보연락 체계
- 농장별 Risk Level과 공공관제 확인 우선순위
- 소모품 분할조달·유효기간·폐기 관리기준
- 지역밀집 설치를 활용한 정기점검·장애복구 동선
- 공식검사 결과와 장치경보를 비교할 수 있는 지역 데이터셋
- 충북 실증결과를 다른 지자체가 검토할 수 있는 사용평가서

### 3. 지역산업과 인력 효과

초기에는 일자리 수를 임의로 제시하지 않는다. 실제 고용·조달·교육이 발생한 뒤 다음 지표로 지역경제 기여를 측정한다.

| 영역 | 측정지표 |
|---|---|
| 지역조달 | 충북 소재 기업·기관에 지급한 제작·설치·시험·유지관리 금액 |
| 전문인력 | 지역 내 채용·전환된 기계·전기·AI·수의방역 인력 수 |
| 교육 | 농장·지자체·전문기관 교육인원과 이수율 |
| 산학연 협력 | 공동시험·자문·데이터 협약 건수 |
| 유지관리 | 지역 현장출동 비율과 평균 장애복구시간 |
| 사업확산 | 후속 시군·농가·계열화사업자 참여 수 |
| 지식자산 | 표준절차, 시험보고서, 데이터셋과 특허·노하우 축적 |

지역산업 효과는 실제 계약서·세금계산서·급여대장·교육기록으로 확인한다. 단순히 사업비 전체를 지역경제 효과로 간주하거나 간접고용을 근거 없이 배수로 확대하지 않는다.

### 4. 지역사회와 공급망 효과

조기경보가 초동대응을 앞당기고 추가 발생을 줄이는 결과가 실증되면 다음과 같은 간접효과를 기대할 수 있다.

- 비발생 인접농가의 예방적 살처분과 이동제한 부담 감소 가능성
- 계란·육계·오리 생산과 출하중단 범위 축소 가능성
- 사료·운송·도계·집하장 등 연관 공급망 충격 완화 가능성
- 사체처리와 매몰·렌더링 과정의 환경·민원 부담 감소 가능성
- 반복 발생지역에 대한 데이터 기반 방역교육과 점검 우선순위 개선
- 충북 실증모델의 충청권·중부권 확산 기반 확보

이 항목들은 지역사업 전후의 생산·출하·가격·이동제한 자료와 비교지역 자료를 확보한 뒤 평가한다. 축산물 가격은 전국 수급·사료비·계절수요의 영향을 크게 받으므로 단순 가격변화를 시스템 효과로 귀속하지 않는다.

## 12.5 타 감염병 확장 가능성

### 1. 재사용 가능한 공통 플랫폼

AIV 사업에서 검증된 모든 기술을 다른 감염병에 그대로 적용할 수 있는 것은 아니다. 다음 공통기능은 재사용 가능성이 있다.

| 공통기능 | 재사용 가능 범위 |
|---|---|
| 장치 제어 | Actuator·Sensor 상태관리, 오류복구, 원격점검 |
| 검사 오케스트레이션 | 시료식별, 전처리 단계기록, 분주·반응시간 관리 |
| 영상판독 | 고정 촬영환경, ROI 탐지, 이미지 QC 구조 |
| 데이터 모델 | Farm·Device·Sample·Kit Lot·Result·Alert·Action 연결 |
| 시계열 분석 | 농장별 기준선, 변화탐지, 재검 로직의 소프트웨어 구조 |
| 공공관제 | 위험등급, 확인대기, 조치이력, 감사로그 |
| 운영서비스 | 소모품 관리, 정기점검, SLA와 보고서 |

### 2. 질병별로 새로 검증할 요소

아래 항목은 질병별로 처음부터 다시 검증한다.

- 어떤 검체가 농장집단을 대표할 수 있는지
- Sampling Point와 채취주기가 적절한지
- 전처리 과정이 표적물질을 안정적으로 보존하는지
- 사용할 신속키트·바이오센서와 기준검사가 무엇인지
- 검출한계·민감도·특이도·교차반응이 현장목적에 적합한지
- 양성·음성·Invalid와 반정량 신호의 해석범위
- 질병별 위험단계와 공식신고·방역조치 연결절차
- 감염성 시료 취급을 위한 생물안전과 폐기조건
- 동물용의료기기 등 관련 인허가·품질요건
- 검사 1회 원가와 공공고객의 지불의사

AIV 성능자료를 다른 축종이나 병원체의 정확도 근거로 전용하지 않는다.

### 3. 확장 후보 선정 Gate

| Gate | 판단질문 | 통과 근거 |
|---|---|---|
| 공공문제 | 반복 감시가 필요한 명확한 방역문제가 있는가 | 발생자료·정책수요·기관 인터뷰 |
| 검체 | 자동채취 가능한 대표 검체가 있는가 | 전문기관 시료설계 |
| 검사 | 현장 자동화가 가능한 검출수단이 있는가 | 키트 IFU·예비시험·기준검사 |
| 안전 | 농장과 장치에서 안전하게 취급 가능한가 | 생물안전·폐기·세척계획 |
| 제도 | 보조경보와 공식검사의 역할을 구분할 수 있는가 | 규제·방역기관 검토 |
| 경제성 | 반복검사 비용보다 검증 가능한 편익이 큰가 | 사용량 시나리오와 공공 순편익 |
| 운영성 | 소모품·유지관리·교육을 지속 공급할 수 있는가 | 유료실증·SLA·공급계약 |

### 4. 확장 순서

1. AIV 1 Sampling Point / 1 Analysis Unit의 기계·검사·데이터 반복성을 확보한다.
2. 전문기관 기준검사 비교와 충북 농장실증으로 경보의 유용성을 검증한다.
3. 동일 AIV 내에서 Multi-point Monitoring과 지역 관제를 고도화한다.
4. 도계장·집하장·차량 이동거점 등 관련시설은 시설별 Sampling 방식을 별도 검증한다.
5. 다른 축종·감염병은 독립된 전문기관 시험·규제검토·사업성 분석을 거쳐 별도 제품으로 개발한다.

따라서 타 감염병 확장은 단순한 TAM 확대 문구가 아니라, AIV에서 축적한 **자동검사·데이터·공공관제 기반을 재사용하되 질병별 생물학적 성능과 제도요건을 다시 검증하는 조건부 확장전략**으로 정의한다.

## 12.6 기대효과 검증 로드맵

[10. 추진 일정](https://github.com/thjm0829/avian-ai-10-roadmap)의 Gate와 기대효과 검증범위를 다음과 같이 연결한다.

| 단계 | 시기 | 기대효과 검증범위 | 주장하지 않는 항목 |
|---|---|---|---|
| Gate 1~2 | 2026~2027 | 자동검사·기록·재검 기능 | 농장 방역효과 |
| Gate 3 | 2027년 4분기~2028년 1분기 | 정상농장 가동률·관리자 개입·환경내구성 | 감염 탐지성능 |
| Gate 4 | 2028년 | 전문기관 기준검사 비교·오류지표 | 지역 피해절감 |
| Gate 5 | 2028년 4분기~2029년 1분기 | 2~5개 농장 경보·재검·공식검사 연결 | 살처분 감소율 |
| Gate 6 | 2029년 | 유료실증 운영비·사용성·공공수요 | 장기 재정효과 |
| Gate 7 | 2029년 4분기~2030년 | 충북 10개 농장 운영·공공관제·순재정효과 후보 | 전국 일반화 |
| Gate 8 | 2030~2031년 | 다지역 재현성·추가 발생·재계약·확산효과 | 검증 없는 타 질병 성능 |

### 단계별 판단원칙

- 기술 KPI가 충족되지 않으면 방역·경제효과를 확대해석하지 않는다.
- 공식검사 Label이 부족하면 정확도 대신 데이터 수집·운영성과를 보고한다.
- 오경보·추가검사·현장출동 증가비용을 편익에서 제외하지 않는다.
- 비교군과 외부요인을 확보하지 못하면 추가발생·살처분 감소의 인과성을 주장하지 않는다.
- 유료실증과 재계약이 확인되지 않으면 지역확산 효과를 확정하지 않는다.
- 검증결과가 충분하지 않으면 시스템 역할을 자동 시료관리·검사기록·판독품질관리 장치로 조정한다.

## 12장 종합 기대효과

본 사업의 직접효과는 농장 내부 반복검사를 자동화하고 결과·이미지·재검·조치이력을 표준화하는 것이다. 운영효과는 위험신호 확인과 공식검사 연결시간을 단축하고 공공 방역자원의 우선순위 판단을 지원하는 것이다. 장기 공공효과는 이러한 시간단축이 실제 농장 간 추가 전파와 예방적 살처분, 방역재정과 공급망 충격을 줄였는지를 비교실증으로 확인하는 것이다.

> **농가에는 반복검사와 대응절차의 표준화, 지자체에는 위험농가 선별과 공공관제, 방역기관에는 공식검사 연결을 위한 추적 가능한 데이터, 충북에는 지역 단위 실증·운영모델을 제공하고, 검증된 공통기술을 기반으로 다른 축종·감염병에 조건부로 확장한다.**
